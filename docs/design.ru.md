# Как устроен RepoCards

Загрузка публичных данных отделена от генерации SVG. Рендерер — чистая функция,
получающая сведения о репозитории и палитру. Это упрощает проверку экранирования
и позволяет повторно использовать карточку без работающего сервера.

SVG — XML: имя и описание нельзя вставлять как разметку. Все внешние строки
экранируются, управляющие символы XML удаляются. В карточке нет внешних картинок,
скриптов и foreignObject. Ошибка необязательного API не превращается в успешный
статус: вместо этого выводится unavailable.

Для собеседования: различие escaping и validation, источники DOM XSS,
ограничения публичного API и честное представление устаревающих данных.
Следующий этап — переносимые темы и явная дата получения метаданных.
